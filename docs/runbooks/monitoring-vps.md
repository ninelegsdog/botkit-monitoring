# Runbook: MonitorVPSDown

## Симптомы
- `MonitorVPSDown` — TCP/22 к мониторинговому VPS (31.76.11.198) не проходит 5+ минут.

## Диагностика
1. Проверка сетевого подключения к 31.76.11.198:22.
2. `curl http://31.76.11.198:3001` — Kuma на мониторе (если доступен).
3. Проверка WG-туннеля predator на монитор.
4. Проверка E2E-туннеля.
5. Kuma на мониторе не сообщает о своей смерти — этот алерт единственный внешний наблюдатель.

## Лечение
- Если монитор недоступен: проверить сетевое подключение, брандмауэр, статус хоста 31.76.11.198.
- Если только TCP/22 недоступен: проверить sshd на мониторе, nftables/UFW правила.

## Ожидаемый результат
Мониторинговый VPS доступен по TCP/22, алерт гаснет.
